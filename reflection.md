How does writing a docker-compose.yml file make a cloud engineer's job easier compared to manually typing commands?
Writing a **docker-compose.yml** file makes a cloud engineer’s job easier because all container settings are stored in one file. Instead of 
typing many commands manually, the engineer can start the entire application with one command. It also makes deployments faster, 
consistent, and easier to repeat.

What happens if you make an indentation error (like using a Tab instead of Spaces) in a YAML file?
A YAML indentation error can cause the file to become **invalid** and prevent Docker Compose from running. Using a Tab instead of spaces 
may result in an error message when the file is read. Therefore, proper and consistent indentation is important in YAML files.

Why did we use environment variables (like MYSQL_PASSWORD) in the Compose file?
We use environment variables like **MYSQL_PASSWORD** to provide configuration values to the containers. They make it easier to change 
settings without modifying the application code. They also help keep sensitive information, such as passwords, separate from the 
application configuration.
