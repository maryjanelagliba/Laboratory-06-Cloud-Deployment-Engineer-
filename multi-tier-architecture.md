**The Web/Application Tier: What is its role?**
The Web/Application Tier serves the user interface and handles HTTP/HTTPS requests from users. It processes application logic such as 
login, registration, and submitting information. It also communicates with the database to retrieve and store data.

**The Database Tier: What is its role? **
The **Web/Application Tier** serves the user interface and handles HTTP/HTTPS requests from users. It processes application logic such as 
login, registration, and submitting information. It also communicates with the database to retrieve and store data.

**Why separate them? **
Separating the Web/Application Tier and Database Tier improves **security and performance**. It allows each tier to be managed, updated, 
and scaled independently. It also protects sensitive data by keeping the database separate from direct user access.
